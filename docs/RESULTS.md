# Understanding and Interpreting the Results

This document explains how to interpret the numerical values and groupings generated by the code similarity analysis engine.

## 1. Interpreting Similarity Scores ([0.0 - 1.0])

The similarity score is a normalized value calculated using Tree Edit Distance (ZSS or APTED) over normalized Parse Trees. It typically ranges from `0.0` to `1.0`:

- **1.0 (Identical):** The structural logic and syntax trees of both files match completely. This indicates identical implementation of logic, regardless of superficial changes like variable renaming or indentation adjustments.
- **Intermediate Values (e.g., 0.5 - 0.9):** Partial structural reuse. Parts of the code share common patterns, loops, or functions, while other sections differ. 
- **0.0 (Completely Different):** No significant structural or logical similarities were found between the analyzed source files.

### Calculation Logic
The index is derived via:
```python
def SimilarityIndex(d, T1, T2):
    if d > max(T1, T2):
        s_alt = 1 - (d / max(T1 + T2, 1))
        return round(s_alt, 2)

    m = max(T1, T2)
    s = 1 - (d / m)
    return round(s, 2)
```
Where `d` is the edit distance, and `T1/T2` represent the total node counts in each respective Parse Tree.

## 2. Interpreting Grouping and the Similarity Threshold

- **What is the Threshold?** 
  The threshold is a configured percentage cutoff (ranging from `0%` to `100%`, mapped internally to `0.0` to `1.0`). 
- **How Grouping Works:** 
  Only files whose mutual similarity score meets or exceeds the specified threshold will be grouped together as potential matches or code duplicates. 
- **Adjusting the Threshold:**
  - **Higher Threshold (e.g., 85% - 95%):** Yields fewer groups and stricter matches. Only files with nearly identical structures will be clustered together, reducing false positives.
  - **Lower Threshold (e.g., 50% - 70%):** Yields more matches and broader groups. Useful for catching heavily refactored code or broader patterns of code reuse, though it may introduce more noise.
